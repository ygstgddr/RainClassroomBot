# Windows 安装、升级与卸载

## 安装

双击 `RainClassroomBot-0.8.8-Windows-x64-Setup.exe`，阅读说明后选择安装目录，按需勾选桌面快捷方式。默认安装到 `%LOCALAPPDATA%\Programs\RainClassroomBot`，仅供当前 Windows 用户使用，无需管理员权限。

安装包已包含 Python 与程序依赖；电脑仍需安装 Microsoft Edge 和 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/consumer/)。安装器不会自动下载安装浏览器组件。安装完成后可以从开始菜单打开程序。

默认界面点击“登录”后打开内置浏览器，登录成功后自动进入课程页。内置浏览器默认静音，按站点保存登录。首次使用内置浏览器可能需要重新登录。

## 覆盖升级

### 软件内更新（0.8.7 起）

1. 打开“站点与设置 → 软件更新”，登录前也可使用，点击“检查更新”。
2. 有更高的正式版时可展开更新说明，点击“下载更新”。后台下载显示进度，可以取消后重试；不会启动学习浏览器。
3. 下载并校验通过后，先暂停任务并结束手动打字，等待当前操作停止，再点击“安装并退出”。工作台保存暂停状态、停止专用工作进程，启动安装向导并退出。
4. 安装向导默认使用当前程序目录。继续使用这个目录可以保留登录、选课、进度和配置；完成后可勾选启动工作台或从快捷方式重新打开。

只检查本项目 GitHub 正式版，不自动安装、不降级。源码或演示模式可以查看更新，但不能启动覆盖安装。缺少安装包、缺少校验信息、网络失败或文件校验失败时会提示重试或查看发布页；已安装文件不会被下载过程修改。安装程序若被系统阻止，工作台保留窗口，任务维持暂停。

第一次使用此功能，需要先安装包含更新模块的新版本；旧版不会凭空出现新按钮。本轮仅更新源码，尚未构建或发布包含此功能的安装包。

### 手动覆盖

先正常退出助手及其管理的 Edge。安装版会记住先前的安装目录。便携版升级时，手动选择原 `RainClassroomBot.exe` 所在目录。

安装器只更新程序文件。已有 `config/config.yaml`、`data`、`sites`、`edge_profile`、`webview2_profile`、`logs` 会保留。选择新目录则是独立安装，不会自动复制旧账号。

安装时如提示程序占用文件，请先正常退出程序再继续，不要强制终止正在执行的任务。

## 卸载

Windows“设置 → 应用 → 已安装的应用”中找到“雨课堂学习工作台”，选择卸载。也可使用开始菜单中的卸载入口。

卸载会移除本次安装的程序文件及快捷方式，但保留配置与学习数据，安装目录可能不会变空。若不再需要账号数据，确认后自行删除剩余目录。

## 开发者构建

1. 运行 `build.ps1` 构建并检查便携版。
2. 安装 [Inno Setup 6.7 或更高版本](https://jrsoftware.org/isdl.php)。
3. 执行 `powershell -ExecutionPolicy Bypass -File build-installer.ps1`。
4. 若编译器不在默认位置，指定 `-Compiler "D:\Tools\Inno Setup 6\ISCC.exe"`；可用 `-SourceDir`、`-OutputDir` 指定程序目录与输出目录。

输出在 `dist/installer`，同时生成 `.sha256` 与软件内更新使用的 `SHA256SUMS-X.Y.Z.txt` 校验文件。发布时将安装包和校验文件一起上传 GitHub Release，约定见 [更新维护说明](UPDATES.md)。安装脚本为 `installer/RainClassroomBot.iss`，按允许清单打包文件，禁止加入账号目录。`AppId` 在升级时必须保持不变。

当前本地安装包未使用商业代码签名证书签名，发布者不会显示为已验证的企业身份。
